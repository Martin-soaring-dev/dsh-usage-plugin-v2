# v1.12.1 — 2026-08-19

## 修复

- 修复 Harness 重启后“用量与消耗”面板只显示少量/当前官方模型记录，必须先发送一条消息后才恢复完整历史用量的问题。
- API 读取用量数据前会重新解析当前 Harness session 的 workspace，并在必要时加载正确的 `dsh-usage/usage-records.json`。
- `sessionPolicy()` 不再无条件优先使用启动阶段缓存的 policy；会先尝试解析当前 session，避免启动时的旧/回退 workspace 阻止后续切换到真实会话目录。
- 保留现有历史记录合并与按时间去重逻辑，不改变用量数据格式、计价方式或已有导出文件。

## 版本

- `package.json`: `1.12.0` → `1.12.1`
- 本版本为 bugfix patch release。
