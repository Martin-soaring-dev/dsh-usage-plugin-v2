# v1.12.2 — Fix Harness profile detection for self-update

## Fixed

- Fixed GitHub Release installation failing with `无法定位当前 Harness profile` when the plugin is mounted under a Harness `plugins/` directory instead of a conventional `node_modules/` layout.
- `profileRootFromModule()` now supports both `<profile>/node_modules/...` and `<profile>/plugins/...` layouts.
- Added updater tests for the Harness `plugins/` layout and for unknown layouts.

## Upgrade note

This release only changes self-update profile detection. Existing usage records, pricing data, balance-provider configuration, and UI behavior are unchanged.

After installing the update, fully restart Harness before verifying the installed version.
