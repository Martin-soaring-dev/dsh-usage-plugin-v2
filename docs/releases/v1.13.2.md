# v1.13.2 — SiliconFlow balance layout polish

This patch focuses on the SiliconFlow balance page and is also intended as the first practical verification of the v1.13.1 self-updater fix.

## Changes

- Reordered the SiliconFlow balance page so the primary account balance is followed immediately by the detailed balance cards (recharge balance, legacy/free balance, query time, etc.).
- Moved explanatory blue information boxes below the balance cards, so important financial information is presented first.
- Merged the zero-balance explanation and API field definitions into a single “SiliconFlow 查询说明” block.
- Kept the credential-reading rules as a separate lower-priority information block below the balance result.

## Update-chain verification

v1.13.2 is deliberately a small UI patch after v1.13.1. It should be used to verify that the fixed updater can migrate/update the active DSH web profile correctly from v1.13.1 to v1.13.2 and validate the installed version before reporting success.
