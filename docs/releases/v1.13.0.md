# v1.13.0 — Provider-aware pricing, FX conversion, and usage UI improvements

## Highlights

- Added **API provider** to the model usage table. When one model is used through multiple providers, all observed providers are shown.
- Added **provider-aware pricing** so third-party calls no longer inherit DeepSeek Official pricing simply because the model name contains `flash` or `pro`.
- Added **SiliconFlow pricing** for verified models.
- Added **DigitalOcean Serverless Inference pricing in USD** and automatic conversion to CNY using the latest available USD/CNY exchange rate.
- Added an **USD/CNY exchange-rate panel** in the price page, including reverse CNY/USD rate, rate date, source, status, and manual refresh.
- New DigitalOcean records store the USD/CNY rate and rate date used at capture time. Legacy records without a stored rate fall back to the latest available rate when estimated.
- **Alibaba / Qwen is intentionally not priced yet**; calls and token usage remain visible while cost is counted as ¥0.
- **AMD GPU Cloud DeepSeek V4 Flash is treated as free** and counted as ¥0 while usage is still tracked.
- Balance-query information boxes now have additional top spacing for clearer visual hierarchy.

## Exchange-rate behavior

The plugin requests the latest published USD/CNY reference rate from Frankfurter (`api.frankfurter.dev`) without an API key. The rate is cached in memory for the current Beijing-time day. If a refresh fails after a valid rate has already been loaded, the previous in-memory rate remains available and is marked as cached/stale.

CNY-priced providers are unaffected by the FX multiplier. DigitalOcean cost is calculated in USD first, then multiplied by the USD/CNY rate so all displayed totals remain in RMB.

## Notes

- Historical DigitalOcean records created before v1.13.0 do not contain the rate that was in effect when the call happened, so their RMB cost is an estimate using the latest available rate.
- Alibaba / Model Studio pricing is deferred because the current history contains several Qwen model snapshots and pricing can depend on exact model code, region, context length, caching mode, or plan.
